# 🌌 Riyanda Prima Anugerah — Portfolio Website

A personal portfolio website for **Riyanda Prima Anugerah** — AI Engineer & Data Engineer. Built with **React**, **Vite**, and **Vanilla CSS** featuring a **Neural Dark** futuristic aesthetic with interactive particle backgrounds and modal showcases.

🌐 **Live Website**: [https://riyandaprimaa.github.io](https://riyandaprimaa.github.io)

---

## ✨ Features & Highlights

- **🧠 Interactive Neural Particle Background**: HTML5 Canvas particle network that responds dynamically to mouse movements and left-click shockwaves.
- **⚡ Typing Role Switcher**: Smooth animated role rotation (`AI Engineer` ↔ `Data Engineer` ↔ `ML Practitioner`).
- **🔍 Fullview Lightbox Modal**: Click any photo (Profile, Project Screenshots, Netherlands Exchange) to view in an uncropped modal lightbox.
- **🖼️ Project Detail Popup Modal**: Clickable project cards popping up an interactive detail modal with overview highlights, GitHub links, and live demo links.
- **💼 5 Featured Projects**:
  1. **Organic Waste Detection & RAG Chatbot** (YOLOv8/v11, LangChain, Streamlit)
  2. **n8n LLM Automation — Invoice & Social Media** (n8n, OpenAI, Telegram Bot)
  3. **VLM-Based ID Card (KTP) Extraction** (DeepSeek-OCR, PyTorch, FastAPI)
  4. **Stunting Analysis Dashboard** (Streamlit, Looker Studio, Plost)
  5. **Data Management Platform & AI Churn Maintenance** (Apache Iceberg, MinIO S3, Seeknal/DuckDB, LightGBM)
- **🌍 International Education Carousel**: Interactive photo gallery documenting exchange studies at **The Hague University of Applied Sciences, Netherlands** (IISMA 2024 Awardee).
- **🎨 High-Contrast "Neural Dark" Theme**: Dark navy fill with glowing cyan/purple neon accents, glassmorphism blur, and a minimal scroll progress bar.

## 🚀 Local Development Setup

To run this project locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/riyandaprimaa/riyandaprimaa.github.io.git
cd riyandaprimaa.github.io

# 2. Install dependencies
npm install

# 3. Start the local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the website.

---

## 📦 Production Build & Deployment

To create an optimized production build:

```bash
# Build production bundle to dist/
npm run build
```

This project deploys for free on **GitHub Pages** using GitHub Actions or direct branch deployment.
